# op-exence

## Portfolio

Expense tracker with a Rust API, Java/Spring frontend, and Postgres. Supports categories, shops, and monthly summaries.

## Development

```bash
npm run dev
```

- UI: http://localhost:8081
- API: http://localhost:8080

docker compose up --build
